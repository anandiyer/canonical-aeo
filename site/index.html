Critical · +6 pts robots.txt

You're blocking the crawler that feeds ChatGPT's citations

Your robots.txt blocks OAI-SearchBot and PerplexityBot alongside the training crawlers. Blocking GPTBot is a legitimate choice — it's training data. But OAI-SearchBot is what fetches pages to cite in answers. Blocking it removes you from ChatGPT's results entirely, which is almost certainly not what you meant.

robots.txt — replace lines 4–6 
- User-agent: OAI-SearchBot
- Disallow: /
- User-agent: PerplexityBot
- Disallow: /
+ # Training crawlers — still blocked, your call
+ User-agent: GPTBot
+ Disallow: /
+
+ # Answer crawlers — these produce citations. Allow.
+ User-agent: OAI-SearchBot
+ Allow: /
+
+ User-agent: PerplexityBot
+ Allow: /
+
+ User-agent: Claude-SearchBot
+ Allow: /

Put it at https://northwind.io/robots.txt

Critical · +5 pts /, /product, /pricing

Your pages are empty without JavaScript

We fetched your homepage the way a crawler does and got 214 characters of text. A real browser renders 4,180. Your content is client-rendered, and most answer-engine crawlers don't execute JavaScript — so they see an empty shell. This single issue caps everything else on this page.

What a crawler currently sees at northwind.io

<script src="/assets/index-4f2a1b.js"></script>

Fix at the framework level — enable SSR or static prerendering for /, /product and /pricing at minimum. No snippet we can hand you here; this is a build-config change.

How it works

Two thirds of this score is deterministic. We check, we don't guess.

01

Crawl

Fetch up to 10 pages the way a crawler does — no JavaScript — plus robots.txt, your sitemap and response headers.

02

Technical audit

Bot allowlists, schema.org coverage, heading structure, render-without-JS, llms.txt, Content Signals. Pure checks — no model involved, so the same site scores the same twice.

03

Query generation

Read what you sell and to whom, then write 12 buyer-intent questions across fixed shapes — best-in-category, pricing, alternatives, jobs-to-be-done. You can edit them.

04

Ask five engines

Every question goes to ChatGPT, Claude, Gemini, Perplexity and Grok using each one's own native search. We record whether you're named, whether you're linked, and how you're described.

05

Score

Five pillars, 100 points. 75 from the audit, 25 from what the engines actually said.

06

Write the fixes

Generate the real artifact for each gap — the JSON-LD, the llms.txt, the robots.txt diff — built only from content we actually read on your site. Anything we can't source comes back as an obvious placeholder.
